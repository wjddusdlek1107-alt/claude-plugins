# seoyeon-plugins

Claude 플러그인 마켓플레이스입니다.

## 설치

```bash
claude plugin marketplace add wjddusdlek1107-alt/claude-plugins
claude plugin install weekly-sales-report@seoyeon-plugins
```

## 플러그인

- **weekly-sales-report** — 구글시트 `판매관리_2`의 판매내역으로 지난주(월~일) 주간 매출 리포트를 만들어 Slack에 올립니다. Google Drive/Sheets, Slack 커넥터가 필요합니다.
