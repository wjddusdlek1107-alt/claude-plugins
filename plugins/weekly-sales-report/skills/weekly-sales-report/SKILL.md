# 주간 매출 리포트

Google Drive/Sheets 커넥터와 Slack 커넥터가 연결되어 있어야 한다. 연결되어 있지 않으면 사용자에게 연결을 요청하고 멈춘다.

## 고정 기준 (사용자와 합의됨)
- **데이터:** Google Drive에서 제목이 `판매관리_2`인 스프레드시트 → `판매내역` 시트
  - 열: 주문일, 주문번호, 판매채널, 카테고리, 상품명, 옵션, 수량, 판매단가, 결제금액, 배송비 (1행 헤더, 주문일 오름차순)
- **기간:** 오늘 기준 직전 주 월요일~일요일. 비교 기간은 그 전주 월~일.
- **매출:** 결제금액 합계, 배송비 제외 (시트 대시보드와 같은 기준)
- **판매 건수:** 시트 행 개수. 주문 건수는 고유 주문번호 수. 객단가 = 매출 ÷ 주문 건수.
- **채널:** 기본 `#주간리포트-테스트`. 사용자가 다른 채널을 말하면 그 채널.
- **제목:** `📊 주간 매출 리포트 (M/D~M/D)`. 예: `📊 주간 매출 리포트 (10/19~10/25)`

요청에 다른 기준(기간, 채널, 항목)이 있으면 그것을 따른다. 기준이 모호하면 만들기 전에 묻는다.

## 절차

1. **기간 계산.** 오늘 날짜로 지난주 월~일과 전주 월~일을 정한다. 요일은 직접 검산한다.
2. **시트 찾기.** Drive에서 `판매관리_2` 스프레드시트를 검색하고, 시트 이름과 행 수를 확인한다.
3. **행 가져오기.** 데이터는 주문일 오름차순이라 최근 날짜가 아래쪽에 있다. 끝부분부터 범위를 읽어 전주 시작일~지난주 종료일 행이 모두 들어오도록 가져온다. 첫 날 앞 행과 마지막 날 다음 행이 보일 때까지 범위를 넓혀 경계를 확인한다.
4. **집계.** 가져온 행을 CSV 파일로 저장한다 (열: `날짜(MM-DD),주문번호,판매채널,카테고리,상품명,수량,결제금액`, 숫자는 쉼표 없이). 코드 실행 도구로 이 스킬의 스크립트를 실행한다:
   ```
   python scripts/aggregate.py rows.csv --cur MM-DD:MM-DD --prev MM-DD:MM-DD
   ```
   숫자를 직접 암산하지 말고 반드시 스크립트 결과를 쓴다. 출력 끝의 검산(일별 합 = 총매출)이 True인지, 지난주 행 수가 시트의 행 번호 범위와 맞는지 확인한다.
5. **중복 확인.** Slack에서 채널을 찾고, 보내기 **직전에** 최근 메시지를 읽는다. 같은 제목(같은 기간)의 메시지가 이미 있으면 **보내지 말고** 사용자에게 기존 메시지 링크를 알린다.
6. **전송.** 제목 한 줄만 채널에 보낸다. 응답으로 받은 메시지 타임스탬프를 스레드 대상으로 지정해 본문을 스레드 답글로 보낸다.
7. **보고.** 두 메시지 링크, 주요 수치, 기준과 검산 결과를 사용자에게 알린다.

## 스레드 본문 형식

```
**기간:** YYYY-MM-DD(월) ~ MM-DD(일) · 비교: 전주 M/D~M/D
**기준:** 판매관리_2 › 판매내역, 매출 = 결제금액 합계(배송비 제외)

**1. 핵심 지표**          표: 지표 | 지난주 | 전주 | 증감
  총매출 / 판매 건수(행, 증감은 +N건) / 주문 건수 / 판매 수량 / 객단가
**2. 판매채널별 매출**    표: 채널 | 매출 | 비중 | 전주 대비
**3. 매출 상위 5개 상품** 표: 순위 | 상품 | 매출 | 수량 | 전주 대비
**4. 카테고리별 매출**    표: 카테고리 | 매출 | 비중 | 전주 대비
**5. 일별 매출**          표: 날짜(요일) | 매출 | 판매 건수
**요약:** 3~4문장. 증감 원인(상품·채널·카테고리), 최고/최저 매출일.
```

금액은 `1,234,500원`, 비율은 소수 첫째 자리(`+11.2%`, `-5.8%`).
